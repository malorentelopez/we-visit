# Venue QA notes

Script: `npm run qa:venues`

Reference venues used to tune OSM filters and sparse-data UX:

| Venue | Expectation |
| --- | --- |
| Parque Warner Madrid | Rich theme-park POIs (rides) |
| Disneyland Paris | Rich theme-park POIs |
| Museo del Prado | Often sparse in OSM (few indoor exhibits mapped) |

When sparse, the app must show the sparse banner and still allow custom stops / hide / plan from whatever named POIs exist.
